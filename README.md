# 🔐 SecureAuth — Secure Login System

A futuristic and secure authentication system built using **HTML, CSS, and JavaScript** with advanced client-side security concepts like:

- bcrypt password hashing
- Two-Factor Authentication (2FA)
- Session Management
- Brute-force protection
- Input sanitization
- Password strength checking
- Audit logging

Because apparently humans still insist on using `password123`, this project exists to restore some dignity to authentication systems.

---

# 🚀 Features

## ✅ Authentication System
- User Registration
- User Login
- Secure Logout
- Session Persistence using `sessionStorage`
